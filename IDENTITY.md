# IDENTITY — Visual and Voice Identity

## Visual reference

The owner supplied a reference image: a luminous spherical orb against a black background. Preserve:

- Dark, nearly black centre.
- Bright cyan/turquoise illuminated outer ring.
- Electric-blue internal reflections.
- Subtle green highlights.
- Glass-like depth and polished holographic finish.
- Minimal surrounding UI.

The orb should be the centrepiece of the desktop companion, not a dashboard decoration.

## Desktop behaviour

- Floating, transparent, always-on-top companion.
- Movable and resizable, with persisted position.
- Idle, listening, thinking, speaking, working, warning, and recovery states.
- Starts with user login when enabled.
- Does not steal focus.
- Gaming/focus mode suppresses visual interruptions and non-urgent notifications.
- Windows 11 and Arch Linux + Hyprland support.

## Voice direction

Original, appropriately licensed voice with a refined British-English character, medium-low pitch, measured pace, precise pronunciation, natural pauses, warmth, and understated humour. Keep voice provider/model replaceable.

## Interaction modes

Visible companion mode, quiet/background mode, gaming/focus mode, and accessible mobile web mode.
