Connect GitHub to MAX

GitHub requires your own OAuth application before MAX can request authorization.

  1. Register a GitHub OAuth app named MAX. Use this callback URL:
  2. In Render Environment settings, set these three keys: MAX_GITHUB_OAUTH_CLIENT_ID MAX_GITHUB_OAUTH_CLIENT_SECRET MAX_GITHUB_OAUTH_CALLBACK_URL
  3. Save and redeploy. Never paste the client secret in MAX chat.
